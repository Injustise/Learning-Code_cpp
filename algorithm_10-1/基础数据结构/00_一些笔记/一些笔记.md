## 二叉树
- 在包含**中序遍历**的前提下，加上任意另一种遍历，都可以唯一确定一棵二叉树：
  - 前序 + 中序（前序找根，中序分左右）
  - 后序 + 中序（后序找根，中序分左右）
- 前序、中序、后序遍历，本质上都是基于 **DFS** 实现的，区别在于**访问/处理当前节点的时机不同**：
    ```c++
    void traverse(Node* root) {
        if (root == nullptr) return;
        // 前序
        traverse(root->left);
        // 中序
        traverse(root->right);
        // 后序
    }
    ```

#### 并查集（求连通块）
```c++
// 只用路径压缩，均摊复杂度是 O(log n)
int find(int x) {
    if(parent[x] == x) return x;
    return parent[x] = find(parent[x]); // 路径压缩 
}
// 加上按秩合并，均摊复杂度降到 O(α(n))，其中 α 是阿克曼函数的反函数，增长极慢，实际可视为常数。
void unite(int a, int b) {
	a = find(a);
	b = find(b);
	if(a != b) parent[a] = b; 
}
```

## 拓扑排序
- 有向图**存在拓扑排序**，则为**有向无环图（DAG）**。
1. **DFS 写法**：借助 `vis` 数组记录节点状态，`0` 表示从未被访问过，`1` 表示已经被访问过，`-1` 表示正在被访问：
    ```c++
    void dfs(int u) {
	    vis[u] = -1;
	    for(int v : edge[u]) {
		    if(vis[v] < 0) { // 存在环
			    flag = false;
			    return;
		    }
		    if(!vis[v]) dfs(v);
	    }
	    vis[u] = 1;
	    topo.push_back(u); // 拓扑序
    }

    void topo_sort(){
	    for(int u = 1; u <= n; u++) 
		    if(flag && !vis[u]) dfs(u);
    }
    ```
2. **BFS 写法**：
- 环上的节点入度永远到不了 `0`，永远也进不了队列，故若 `topo.size() < n` 则有环：
   ```c++
    void bfs() {
	    while(!q.empty()) { // 用优先队列可以让拓扑序的字典序最小
		    int u = q.top();
		    q.pop();
		
		    topo.push_back(u); // 拓扑序
		    for(int v : edge[u]) {
			    indeg[v]--;
			    if(!indeg[v]) q.push(v);
		    }
	    }
    }

    void topo_sort(){
	    for(int u = 1; u <= n; u++) 
		    if(!indeg[u]) q.push(u);
        bfs();
    }
   ```

## 欧拉回路
- **欧拉道路**，本质“一笔画”。
- 存在欧拉回路（不要求回到起点）的**充要条件**：
  - **弱联通**（无向图下联通）；
  - **无向图**至多有两个奇度顶点；
  - **有向图**至多一个顶点出度比入度大 1、至多一个顶点入度比出度大 1，其余顶点入度等于出度。
  ```c++
  bool euler() {
    for(int u = 0; u < U; u++) {
		int diff = indeg[u] - outdeg[u];
		if(diff == -1) st++;
		else if(diff == 1) ed++;
		else if(diff != 0) return 0;	
	}
    if((st == 1 && ed == 1) || (!st && !ed)) return 1;
	else return 0;
  }
    
  ```
