# 全排列
## 非重集
- 递归实现，借助 `vis` 数组
## 重集
- **先 `sort`**，条件判断：
     ```c++
     if(i > 1 && list[i] == list[i - 1] && !vis[i - 1]) continue;
     ```
## STL - next_permutation
- 按字典序生成下一个排列（可重集），故也得**先 `sort`**：
     ```c++
     do {
		print_list(list)
	} while(next_permutation(list + 1, list + n + 1));
     ```

## 数组
- 递归实现，借助 `vis` 数组决定 “选与不选”。
## 二进制

# 回溯
- 在递归构造中，把生成和检查过程有机结合起来（**剪枝**），从而减少不必要的枚举。
- 这类题目的关键就在于**优化剪枝**：
  -  “八皇后”借助“放置规则”及时判断出不合法位置，省去不必要的枚举；
  -  “困难串”只枚举**判断当前串**的后缀，避免枚举长度为偶数的子串时的重复功；
## 二叉树枚举
1. **自下而上**：递归实现，每次选择两个结点/子树，合并成一颗新子树，再放回数组里，直到数组里只剩一个子树（即一种情况的二叉树）。部分二叉树存在重复枚举，时间复杂度 `O(s!⋅(s−1)!)` **阶乘级别**。
2. **自上而下**：划分子集实现，每次枚举左子树用到哪个子集，右子树就是剩下的子集。枚举不重不漏，时间复杂度 **卡特兰数级别（指数级别）**。

# 路径寻找
- **BFS**：边权为 `1`，`queue` 队列实现。
- **Dijkstra**：边权不为 `1`，`priority_queue` 优先队列实现。（由于边权不为 `1`，需要**记录当前状态的最优解**）
- 这类题目的关键在于**状态存储**和**状态转移**
## 状态存储

### 哈希（hash）
1. **拉链法**：
   ```c++
   int Hash(State s) {
	int h = _Hash(s); // 状态 --> h
	int u = head[h];
	for(; u; u = nt[u]);
	
	nt[cnt] = head[h]; // 头插
	head[h] = cnt; // h 作桶，h --> cnt
	 
	return cnt;
     }  
   ```

# 迭代加深搜索
- 本质：通过一个外层循环（迭代）设定深度限制 `maxd`，做带深度限制的 `DFS`。
- 这类题目的关键在于利用题目条件和**深度限制进行剪枝（启发函数）**：已知当前深度 `d` 和最大深度 `maxd`，结合题目条件，**乐观**判断当前节点能否到达目标节点，不行就剪掉。
