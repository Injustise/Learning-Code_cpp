### 一些笔记
1. 在 C/C++ 中，严格来说只有**值传递**（Pass by Value）和**引用传递**（Pass by Reference），而**指针传递**（Pass by Pointer）本质上是值传递，不过传递的值是一个内存地址罢了.
    - 值传递：
        ```c++
        void func(int x) {
            x = 20; 
        }
        int main() {
            int a = 10;
            func(a);
        }
        ```
        - 实参 `a` 在地址 0x100，值为 10。
        - 形参 `x` 在地址 0x200，值为 20。
        - `x` 为 `a` 的一个副本，两者完全独立
    - 指针传递：
        ```c++
        void func(int *p) {
            *p = 20;
            p = nullptr; 
        }
        int main() {
            int a = 10;
            func(&a); 
        }
        ```
        - 实参 `a` 在地址 0x100，值为 20。
        - 形参 `p` 在地址 0x200，值为 nullptr
        - `p` 可以解引用，通过地址改变 `a` 的值
 
    PS: 当你写 `void func(int arr[])` 时，C/C++ 会把它视为 `void func(int* arr)`。数组名退化为指针（值传递）。
    但当你写 `int arr[10]` 时，这里的 `arr` 是**指针常量**（`int* const`），它指向的地址是固定的，不能修改。
    但当你把它传给函数后，函数里的形参又是一个普通的指针变量时，是可以 `arr++` 的。
    - 引用传递：
    ```c++
    void func(int &ref) {
        ref = 20; 
    }
    int main() {
        int a = 10;
        func(a);
    }
    ```
    - 实参 `a` 在地址 0x100，值为 20。
    - 形参 `ref` 在地址 0x100，值为 20。
    - `ref` 为 `a` 的一个别名，两者相互绑定。
