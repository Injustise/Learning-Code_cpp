### 一些笔记
1. `std::uniform_int_distribution` 是 C++11 标准库 `<random>` 中定义的一个类模板，**依靠随机数引擎来获取指定范围内的随机数**。
    - 用法：
    ``` c++
        std::mt19937 gen(seed); //1.创建引擎
        std::uniform_int_distribution<int> dist(0, 999999); //2.创建分布对象 dist
        int code = dist(gen); //3.分布调用引擎生成随机数
    ```
    - 注意：使用 `std::uniform_int_distribution` 的前提是有一个==随机数引擎==，分布对象本身不产生随机性，而是负责**映射**：将引擎输出的原始随机数转换为所需范围内的均匀分布整数。

2. 取模运算的劣势:
    - 假设你有一个随机数引擎 `gen`，它生成的整数范围是 [0, 2^32 - 1]。如果你想要 [0, 999999] 的随机数，直接使用 `gen() % 1000000` 会有一个问题：
        - 2^32 不能被 1000000 整除，余数不为 0，
        - 这意味着，某些数字（特别是较小的数字）出现的概率会比其他数字略高，
        - 这种现象称为**模偏差（modulo bias）**。
