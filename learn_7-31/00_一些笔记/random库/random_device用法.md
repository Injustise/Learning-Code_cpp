### 一些笔记
1. `std::random_device` 是 C++11 标准库 `<random>` 中的一个**非确定性随机数生成器**。
2. 但其核心定位通常**不是用来生成大量随机数**，而是用来为 `std::mt19937`、`std::mt19937_64` 等伪随机引擎**生成种子**，原因在于：其每次调用都可能是一个系统调用，开销远高于普通的算术运算。
    ``` c++
        std::random_device rd;
        std::mt19937 gen(rd()); //推荐，生成种子
        //for(int i = 1; i <= 1000000; i++) {
        //    unsigned x = rd(); //极不推荐，每次都走系统调用，非常慢
        //}
    ```
3. 但如果你只需要**少量高质量随机数**，或者对不可预测性要求极高（例如生成密钥），可以直接使用 `std::random_device`。
    ``` c++
        std::random_device rd;
        unsigned key = rd(); //生成一个不可预测的密钥
    ```
4. 故 `std::random_device` 太贵重、太慢，不适合干粗活。用它的“不可预测性”来点燃一个高效的伪随机引擎，是 C++ 中平衡安全与性能的经典做法。
