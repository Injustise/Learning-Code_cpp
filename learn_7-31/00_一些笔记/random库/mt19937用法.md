### 一些笔记
1. `std::mt19937` 是 C++11 标准库 `<random>` 中定义的一个类，**依靠种子来获取随机数** 
    - 用法：
    ``` c++
        mt19937 gen;  //默认种子 5489
        //mt19937 gen(5489) //完全等价
        auto x = gen() % 100; //x：0 ~ 99
     ```  
    - **使用 static（推荐）**：
    ``` c++
        static unsigned seed = static_cast<unsigned>(chrono::system_clock::now().time_since_epoch().count());
        static mt19937 gen(seed);
    ```
    当多次调用时，第一次调用依据时间设定种子，后续调用 `gen` 对象会接着上次的旋转状态继续生成随机数。避免以下问题：
      1. 效率：每次调用，都会在内存中重新分配 2.5KB 空间，重新执行 624 轮的复杂初始化运算，效率降低。
      2. 随机性：`time_since_epoch().count()` 的精度虽然是纳秒/微秒，但在极其频繁的调用下，`seed` 的值几乎不变。而种子相同意味着生成的第一个随机数必然相同，随机性破坏。
>mt 是 Mersenne Twister（梅森旋转算法）的缩写，该算法是由松本真（Makoto Matsumoto）和西村拓士（Takuji Nishimura）于 1997 年发明。
>19937 代表该算法的周期为 $2^{19937}-1$ 。
